# 景点信息卡：深圳小范围试点

2026-10-23：用户确认采用“高德确认地点、官方来源提供参观事实、维护者逐项核验入库”的方案。当前实现首个馆区的本地信息卡，不是全深圳景点推荐或自动联网事实采集。

## 使用入口与数据流

正式“多站点行程”页面搜索并点选地点后，可展开该站的“景点参观信息”。只有展开才调用 `POST /api/attractions/lookup`，提交已确认地点的 POI ID、城市编码和 WGS84 坐标。接口只读内置景点库，不调用模型、不重新搜索路线，不改变草案或保存结果。

匹配要求：高德 POI ID 在核验绑定列表内，城市编码相同，坐标距离在维护者指定半径内（首条 150 米）。不按名称模糊合并馆区；重复绑定、城市/坐标不符、未收录均返回 `not_found`。这不是用户身份或行政区认证。

信息卡展示预约、票价、开放信息、各字段来源和查阅日期、待复核日期及官方入口。未知、冲突和过期信息不展示确定性结论。过期时保留来源供用户自行核对；不会自动在线复核。改选地点会中止旧查询，迟到响应不能覆盖新地点；请求失败可重试。

建议游览时长明确为产品建议，不自动写入停留字段。它不参与路线评分、门票预算或指定日期开放判断。

## 首条数据与来源

数据文件：`src/travel_agent/data/attractions_shenzhen.json`。当前只有深圳博物馆金田路馆（历史民俗），不是同心路馆。

2026-10-23 实际高德搜索“深圳 深圳博物馆 历史民俗馆”返回金田路馆/新馆 POI：`B02F38IRTR`、`B0FFGM6YKB`，城市编码 `440300`，归一化 WGS84 坐标约 `22.54639,114.05680`。停车场 POI 不纳入馆区绑定。

逐项比对了公开官方页面的可检索正文：

- [深圳博物馆预约须知](https://mobile.shenzhenmuseum.com/guide)：普通入馆无需提前预约；活动、讲座不纳入该结论。
- [深圳市政府取消预约入场说明](https://www.sz.gov.cn/cn/xxgk/zfxxgj/bmdt/content/post_11451373.html)：交叉核对金田路馆的入馆规则。
- [深圳博物馆参观服务须知](https://cdn3.shenzhenmuseum.com/myOrderNew)：普通参观免费，不扩展为所有服务/特展保证免费。
- [2026 年 10 月恢复开放公告](https://mobile.shenzhenmuseum.com/newsDetail?clazzName=CmsInformation&from=1&resId=8070ff15620a423ba14961a28684acdc&type=2)：与预约须知页面内存在差异的时间表一起保留。开放时刻本轮不作确定结论，标记 `conflicting`。

部分页面直接读取曾超时，本轮核对依据包括官方页面的搜索索引正文，不声称有稳定抓取链路或实时营业证明。数据中的 `checked_at` 是本次查阅时间，不是页面更新日期。首条预约/票价的复核期限暂定 7 天（产品维护参数，非验证出的最优频率），到期必须复核后才可更新日期；不能只改时间维持“已核验”。

## 新增与维护流程

1. 搜索并确认景点具体馆区，记录真实 POI ID、城市、坐标；不要使用停车场或仅凭名称绑定。
2. 分别核对预约、票价和开放信息。优先景点官方与政府来源，记录适用馆区、人群/服务及链接。地图的人均消费 `cost` 不得转成门票。
3. 写入事实状态、内容、来源、实际查阅时间和复核期限。缺信息用 `unknown`，未解决差异用 `conflicting`，都不能保留确定性 `value`。
4. `verified` 必须有非空内容、来源和晚于查阅时间的复核期限；模型校验会拒绝不完整证据、无时区日期或重复事实类型。
5. 运行对应后端测试与前端回归，再在页面检查馆区对应与来源跳转。事实变动需要重新核对，不由模型补齐。
